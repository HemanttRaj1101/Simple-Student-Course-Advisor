# Project Statement

###  Problem Statement 
The challenge addressed by this project is the difficulty students face in choosing an academic path that genuinely aligns with their natural interests
This often leads to poor motivation and sub-optimal learning outcomes. A simple, logic-driven tool is needed to provide an initial, evidence-based recommendation.

### Scope of the Project 
The project scope is focused on creating a **minimal viable product** that demonstrates the concept of logic programming for advisory systems.
* **In-Scope:** Simple keyword-to-course mapping using Prolog facts and rules. [cite_start]Includes three major functional modules.
* **Out-of-Scope:** User interfaces, complex natural language processing, external database integration, or handling multiple conflicting interests.

###  Target Users 
* **Primary:** High school students who are preparing to select their major subject or stream.
* **Secondary:** Academic counselors or parents seeking quick, objective advice.

### High-Level Features
1.  **Interest Matching** (Core Logic)
2.  **Course Suggestion** (Output)
3.  **Fact Base Extension** (Maintainability)
